How the rules engine works

When an order is placed, the middleware looks up the row matching Payer ID + CPT Code + ICD prefix. It then compares each submitted clinical value against the rule requirements and flags any gaps as missing items in the CDS alert card. This database is updated nightly via FHIR Bulk Data sync from each payer.
